About the data and the models
  • Results (.json)  ·  R code  ·  chain runs
  • Data: the four-series factor on the paper's vintage (ALFRED 2025-09-30), February 1967 – July 2025; step 1 a Bayesian one-factor model, step 2 each regime model fit to the posterior-median factor. The plain switching-mean (MSM) model and the switching-quantile (MSQ) models for a grid of quantile levels; no switches. Piger's published Table 2 numbers (MSM AUC 0.51 / F1 0.05; MSQ(0.30) F1 0.91; MSQ(0.50) AUC 0.98 / F1 0.82) are in the footer for comparison.

MSM: Hamilton-style switching mean with normal errors. MSQ(τ): Piger's switching-quantile model with asymmetric-Laplace errors, estimated for τ = 0.20 … 0.80. All regime models use the same priors as the factor page (regime means N(ȳ ± 0.5 s, s²), transition probabilities Beta(29, 1) / Beta(28, 2) on monthly data). Piger's Table 2 reports, for comparison, MSM AUC 0.51 / F1 0.05, MSQ(0.30) F1 0.91, MSQ(0.50) AUC 0.98 / F1 0.82, MSQ(0.70) AUC 0.98 / F1 0.81 and MSQ(0.75) AUC 0.95 / F1 0.70.

Getting it right. The last tab reports Geweke's (2004) joint-distribution tests of the MSM and MSQ(0.30) samplers with P-P plots. 8 chains per model.
